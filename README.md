# 공연 날 도착 길잡이 (olpark-arrival)

올림픽공원 공연 날, 단체 관람객(단체버스·자가용 여러 대·지하철 동행)이 **언제 도착하면 덜 붐비는지** 고르게 돕는 정적 웹앱.
한국체육산업개발(주) 공공데이터 경진대회(2026) 출품용으로 따로 만든 저장소다. 서버·회원가입·외부 유료 서비스가 없다.

## 구조
- `site/` 정적 사이트 (index.html, app.js, style.css, data/*.json). 그대로 아무 정적 호스팅에 올리면 동작.
- `scripts/fetch_data.py` 원본 내려받기 (서비스키 필요 없음)
- `scripts/parse_events.py` 공연 일정 -> 날짜·공연장·시작 시각
- `scripts/build_model.py` 도착 시점별 참고 범위 + 검증 -> `site/data/model.json`, `events.json`
- `data/raw/` 원본 (저장소에 넣지 않음, fetch_data.py로 다시 받음)

## 다시 만들기
```
python scripts/fetch_data.py
python scripts/parse_events.py
python scripts/build_model.py
cd site && python -m http.server 8765
```
`?demo=1` = 가상 공연명 화면(제출 그림용), `?auto=1` = 첫 공연으로 바로 결과(화면 녹화용).

## 쓰는 공공데이터
| 데이터 | 포털 번호 | 쓰는 곳 |
|---|---|---|
| 올림픽공원 입출차 정보 (2024-07, 215,528건) | 15138735 | 도착 시점별 붐빔 범위, 내려 주기(15분 이하) 분리 |
| 주차장 혼잡도 정보 (2025-02 - 2026-08, 699건) | 15164156 | 공연장 옆 주차장이 '혼잡·만차'가 된 시각(시 단위) |
| 실시간 주차현황 API | 15168686 | 당일 숫자 (브라우저에서 바로 호출, CORS 허용) |
| 영문 공연정보 | 15149169 | 공연일자 칸 점검 (등록일로 보이는 행 다수) |

공연 일정·시작 시각은 올림픽공원 홈페이지 공연 안내 화면의 공개 목록을 쓴다(개방 데이터에 아직 없음).

## 검증 원칙
- 입력은 예측 시점에 아는 것만(요일 유형·공연장·시작 시각). 당일 관람객 수·날씨는 쓰지 않음.
- 같은 공연 회차를 한 묶음으로 빼고 맞춰 봄(공연 9일, 5묶음).
- 기준선 = 요일 유형 x 10분 시간대 평균. 시작 시각 정렬 모형이 기준선을 이기지 못해 앱은 '과거 참고 범위'로 보여 준다.

## 라이선스
대회 규정에 따라 저작권은 참가자에게 있고, 수상 시 원천 소스를 기관에 제공한다.
